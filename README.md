# Картишки

Рабочий первый срез CCG: отдельный редактор карт и бой двух игроков.
TypeScript / React / Colyseus 0.18, npm workspaces, русский язык
по умолчанию и английский перевод через i18next. Node >=22.12, npm >=10.

## Запуск

```powershell
Set-Location D:\KARTISHKI
npm ci
npm run dev
```

- Игра: http://127.0.0.1:5173 — гости: две вкладки и «Найти соперника». Аккаунт сохраняет колоду, рейтинг и добычу.
- Поле сражений локально: две вкладки → «Поле сражений» → «Начать игру» (минимум двое). Вторая вкладка с тем же аккаунтом садится за стол как гость. Локальный сервер не ждёт `/health`: меню открывается сразу, без сервера работают только экраны без сети.
- Если сервер падает на старте с `PGlite failed to initialize`, удали `apps/server/data/players` (локальная база гостей и аккаунтов) — она создаётся заново.
- Редактор: http://127.0.0.1:5174.
- Colyseus и API: http://127.0.0.1:2567 (процесс слушает `0.0.0.0`).

Прод: Cloudflare Pages + Render + Neon — [DEPLOYMENT.md](DEPLOYMENT.md).


## Дуэль 1 vs 1 (правила Hearthstone)

- **Стол** — тот же HTML-стол, что и в «Полях сражений» (`apps/client/src/duel/`): жетоны существ, портреты с самоцветами, фитиль и песочные часы, пресеты стола, те же удары/кровь/пыль. Своё существо или силу героя тянут (или кликают) на цель, карту из руки — на стол.
- **Старт**: выбор героя (30 с), случайный первый игрок; первый получает 3 карты, второй — 4 и «Монетку» (+1 мана на ход). Муллиган 30 с: отмеченные карты возвращаются в колоду после добора замен.
- **Ход** 75 с (последние 15 с горит фитиль), затем ход заканчивается сам. Кристалл маны +1 за ход до 10, полный рефилл. Добор в начале хода, рука до 10 (лишняя карта сгорает — публично), пустая колода бьёт усталостью 1, 2, 3…
- **Бой**: болезнь вызова, кроме «Рывка»; «Провокацию» нужно бить первой; сила героя за ману раз в ход (урон — по любому вражескому персонажу, Провокация её не останавливает). Стол — 7 существ.
- **Обрыв связи**: 30 с на возврат (`MATCH_RULES.RECONNECT_S`, токен в `sessionStorage`), выход через кнопку — сдача. Константы — `MATCH_RULES` в `packages/shared/src/index.ts`.

## Наборы карт (Workshop), редактор в игре, честность

- **Набор карт** — один JSON-файл (`CardSet`, `format: 1`: существа, герои, тексты, стол). Его собирают в редакторе («Наборы (Workshop)»: из текущей таверны или импортом), проверяют на честность и публикуют (`PUT /api/card-sets`). За столом набор выбирают в лобби Поля сражений — столы матчатся по набору, все играют одним файлом.
- **Тема набора** (`CardSet.theme`): выбранный набор (главное меню → «Набор карт», хранится в `localStorage`) меняет лица за меню (`wallpaper`, загруженные портреты), музыку меню (`menuMusic`), названия и число уровней (`leveling`, 1–100 строк как есть) и стол (`board`). Всё это задаётся в редакторе на вкладке «Наборы (Workshop)» → «Тема набора».
- **Расы**: встроенные (`autoBattlerTribes`) плюс свои — любая запись в `copy.tribes` с новым id (`abTribes(copy)`); добавляются на вкладке «Расы» редактора и живут после публикации текстов. Сервер не примет существо с необъявленной расой (`unknownTribe`). За столом играют `AB_MATCH_TRIBES` = 5 случайных рас из тех, у кого есть существа в лавке («Без типа» всегда); остальные существа не попадают в лавку и открытие. Список — в `state.tribes` и значке под аномалией.
- **Честность** (`packages/shared/src/fairness.ts`): у каждой механики скрытые баллы; норма — стартовая таверна по тирам. Вердикт `fair / strong / broken`; `broken` сервер не публикует (`422 unfairSet`). Черновик можно проверить через `POST /api/fairness`.
- **Сценарии способностей**: эффект = первое действие + до четырёх шагов (`steps`), которые идут по порядку, каждый со своей целью и множителем. В редакторе есть «Прогон сценария по шагам» — сервер прогоняет триггер на образце стола (`POST /api/simulate-effect`) и отдаёт состояние после каждого шага.
- **Редактор в игре**: кнопка «РЕДАКТОР» в меню открывает редактор во фрейме (`VITE_EDITOR_URL`, по умолчанию `http://127.0.0.1:5174/` в dev и `/editor/` в проде). Открывается только админам (`players.is_admin`, миграция 7): `UPDATE players SET is_admin = TRUE WHERE username = '...'`; остальным по нажатию показывается «В РАЗРАБОТКЕ».
- **Магазин скинов** (вкладка «Скины»): пресеты стола (`BOARD_PRESETS`), рамки героев (`HERO_SKINS`) и платные герои (`PREMIUM_HEROES`) — `packages/shared/src/cosmetics.ts`. Покупки лежат в `player_unlocks`, выбранное — в настройках игрока (`board`, `heroSkin`); рамку видят все за столом, стол — только его владелец. Гости могут выбрать бесплатные столы.
