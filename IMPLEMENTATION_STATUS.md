# Сверка с требованиями — 11 сентября 2026

Проверено по исходникам текущего рабочего дерева. Полное ТЗ ещё не закрыто.

| Требование | Статус | Реализация и ограничения |
|---|---|---|
| TypeScript, React, Pixi.js | Есть | `apps/client/src/main.tsx`, `Board.tsx`; отдельный React-редактор |
| Node.js, авторитетный Colyseus | Есть | `MatchRoom.ts`, `Battle.ts`, `rules.ts`: сервер проверяет действия, фазу, ревизию, ману и цели; руки приватны |
| Возможность desktop-обёртки | Частично | Клиент отделён от сервера, URL настраивается; Tauri/Electron и сборка .exe отсутствуют |
| Русский язык и i18n | Есть | `packages/i18n/src/index.ts`: RU/EN, общий i18next для клиента и редактора |
| Графический движок с самого начала | Есть | Pixi WebGL, интерактивные карты и поле |
| Рисованная мрачная эстетика | Частично | Бумага, зерно, roughjs, неровные контуры; есть цветные акценты |
| Адаптация фотографий | Есть, Canvas | `packages/shared/src/photo.ts`: контраст, порог, Bayer-дизеринг, зерно |
| Живой WebGL-фильтр редактора | Частично | Живой предпросмотр через Canvas CPU; отдельного шейдера нет |
| Анимации уровня Hearthstone | Частично | Наведение, появление, выпад атаки, тряска, разрыв карты; добор из колоды не поставлен |
| Фазы Start → Main → Combat → End | Есть | `apps/server/src/rules.ts` |
| Пять редкостей | Есть | Модель, переводы, редактор, пачки |
| Приветствие, Прощание, Рейдж | Есть, ограниченный набор | Урон, лечение, атака, статусы; новые эффекты требуют серверного кода |
| Контрацептив, Обида, Унижение | Есть | Щит на один удар, здоровье 1, атака 1 |
| Расширяемые типы существ | Есть как данные | Строковые ID; отдельных правил типов нет |
| Автоподбор соперника | Частично | `joinOrCreate('match')`, комнаты по два игрока; нет подбора по диапазону ELO |
| Рейтинговая очередь и ELO | Частично | ELO K=32 после матча двух аккаунтов, лестница топ-10; отдельной ranked-очереди нет |
| Валюта, ежедневные и победные награды | Есть | 100 ✦ в день, 50 ✦ за победу; ничья и поражение без награды |
| Паки по пять карт | Есть | Серверный ролл, гарантия rare+, клиент раскрывает 5 карт |
| Кейсы с рулеткой | Частично | Сервер заранее выбирает приз, клиент крутит ленту; косметики нет, падает карта |
| База профилей, коллекций и колод | Есть | PGlite по умолчанию, PostgreSQL через DATABASE_URL |
| Колода на 30 карт | Есть | Гость — каталог сервера; аккаунт — сохранённая колода |
| Пользовательские колоды | Есть | До 10 колод, только карты из коллекции |
| Отдельный редактор на React | Есть | `apps/editor` |
| Редактирование характеристик, типов и способностей | Есть | Русский интерфейс |
| Загрузка и кадрирование фотографий | Есть | PNG/JPEG/WebP, квадратный кадр, предпросмотр |
| Звуки призыва, атаки, смерти | Есть | Загрузка и проигрывание по серверным событиям |
| JSON/сохранение и загрузка без пересборки | Есть | Каталог JSON на диске; матч берёт снимок |
| Monorepo и .gitignore | Есть | npm workspaces |
| История атомарных коммитов | Не выполнено | Git инициализирован; команды коммита в README |

React HUD читает снимок `session` через `useSyncExternalStore`. Pixi подписывается
на тот же адаптер и серверные события. Аккаунт ходит в `/api/players`. Оба
отправляют намерения в Colyseus; сервер применяет правила и возвращает публичное
состояние и отдельную приватную руку.

Проверки после изменений: `npm test`, `npm run typecheck`, `npm run build`.
`npm run test:browser` требует свободные порты 2567, 5173, 5174 и Chrome.
